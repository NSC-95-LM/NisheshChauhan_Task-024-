# NisheshChauhan_Task(24)

A basic ReactJS application built displaying a simple "Hello, World!" page using React and styling with Tailwind CSS CDN.

## Summary

This project is a minimal React app created with Create React App. It includes a gradient header with the text "Hello, World!" and a secondary heading for the task name: "NisheshChauhan_Task(24) - Task: ReactJS - Hello World".

## What it does

- Renders a simple landing page in React
- Uses a warm orange gradient header for a clean visual effect
- Displays the task name and title text clearly on the page

## Project structure

- `public/` – static assets and HTML template
- `src/` – React source files
  - `App.js` – main component for the page
  - `index.js` – application entry point
- `package.json` – project dependencies and scripts

## How to run

1. Open a terminal in the project folder.
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open the local URL shown in the terminal, usually:
   ```text
   http://localhost:3000
   ```

5. Or go through the GitHub link provided in the Assignment Submission.
